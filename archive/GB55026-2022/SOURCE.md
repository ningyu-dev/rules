## 怎么补

人工在浏览器打开上方公告页 → 点「附件下载」→ 取得规范全文，然后：

```bash
python scripts/archive_pdf.py GB55026-2022 --from-local <文件> --type 官方 \
    --source-page <公告页 URL> --expected-pages <全文页数>
```

`--expected-pages` 会在页数不足时直接告警，避免把节选当全文。
