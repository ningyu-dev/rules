## ⚠️ 开工前必读：三条会改变排期判断的事实

### 1. 这份 PDF 是扫描件，附录 F 与附录 G 只能人工读页

| 项 | 实测值 |
|---|---|
| 页数 | 179 |
| 字体资源 `/Font` | **0** |
| 图像 XObject | 358 |
| 文本层 | **无** |

**结论：附录 F 的五个公式、附录 G 的 27 档数值、表 5.2.34 的表值，在这份 PDF 里是图片，不是文本。**

这三项**没有任何自动化校验的可能**，必须人工翻页读图。执行者若按"核对 85 条"的平均速度估算，会严重低估这三项的耗时。

### 2. 环境无任何 PDF/OCR 工具

实测未安装：`PyMuPDF`/`pdfplumber`/`pypdf`/`pdftotext`/`pdftoppm`/`tesseract`。

**若不引入 OCR 工具链，全部 85 条均为人工工时。** 是否引入由主理人决策（决策 B）。

### 3. 页码需双字段记录

扫描时丢失了页面标签（`/PageLabels` = 0，无元数据）。**PDF 图像页序与规范印刷页码可能不一致**。

因此每条须记两个页码，不一致时**以 `page_printed` 为准**。

## 字段说明

| 字段 | 含义 |
|---|---|
| `证据等级` | 这条依据的可信度：官方原文已抓取 / 公告已验证 / 规范原文待取 / 工程经验 |
| `当前状态` | 这条校核的**四态判定**：通过 / 待确认 ? / 不通过 / 未核对 |
| `缺口` | 需要补什么。`等级*` 表示该条为**安全关键**（涉及溢流/防水/人员安全），S-4 完成前禁止投产 |
| `unresolved` | **允许标记"这条我没读清"**。强行填一个值就是造假，比留空更糟 |

## 不做的事

- **不为省事填推测值**。读不清就标 `unresolved`
- **不以在线版（第三方整理成果）作为核对依据**。其排版可能与官方原文有差异，且可能混入 OCR 错误。仅可用于快速定位
- **不修改 S-3/S-4 相关的 schema**。那是规则库维护者职责，核对人只填内容
- **不在无原文支撑的情况下把"待确认"改为"通过"**
